# Impact Portfolio — Non-Tech Glimpse

> I get things done. I move people. I scale initiatives.

A single-page, impact-first portfolio showcasing leadership, campaign execution, and community operations — built for non-technical opportunities.

**Live:** ` https://pratik-maity.github.io/non-tech-portfolio/ `

### What it highlights
- **Leadership at scale:** 50+ volunteers coordinated, 350+ beneficiaries impacted, 100+ contributors managed
- **Event execution:** 500+ attendees (KGFF), 1,100+ participants (CHIMERA Health Fest)
- **Campaigns:** Daan Mahotsav, Project Lakshay, Mission Arogyan, Glow Drive, Kritika & Kirti
- **Operations:** Stakeholder management, logistics, outreach, content strategy (EN + BN)

### Features
- Clean, recruiter-friendly typography (no stretched fonts)
- Light / Dark mode toggle with full UI adaptation
- Responsive, CSS-only visuals — no external images
- Contact section with mailto integration
- Writera project with Live Demo + GitHub links (update hrefs)
